Start Using Lita

This specialized keyboard layout is designed for typing fluidly in the Lita language.

Important Requirement A compatible Lita font must be installed on your system for this keyboard to render characters correctly.

Installation Steps

  1. Install Keyman: Download and install the latest version of the Keyman application for your respective desktop or mobile platform.
  2. Install the Lita Package: Locate the lita.kmp (Keyman Package) file inside the build folder and open it. Keyman will automatically detect the package and guide you through the layout installation prompt.
  3. Activate the Layout: Select the Lita keyboard from your system's language menu or Keyman toolbar switch to begin typing.
